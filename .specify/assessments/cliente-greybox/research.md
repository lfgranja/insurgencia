## Data & Constraints

As reduções valem somente para o protótipo e nenhum critério da seção as revoga (GDD:1494,1496,1507). [source: `docs/GDD - Insurgência.md:1494,1496,1507`] (confidence: high)

Essa tensão é registrada, não resolvida nesta etapa. [source: GDD:1490,1513-1516; `.specify/memory/STATE.md:5,8`] (confidence: high para ambos os textos; reconciliação **[NV]**)

## Evidence Against the Idea

- **Conflito normativo não resolvido**: GDD §16.3/§16.4 descrevem cliente-servidor, dois clientes e validação no servidor (`:1490,1513-1516`), enquanto o item 1 da SE é single-player local (STATE:5). Se o greybox não exercitar intenções/validação, o item 2 (cliente modificado, GDD:1567) pode exigir retrabalho do cliente — o risco é real, mas a reconciliação pertence à spec. [source: GDD:1490,1513-1516,1567; STATE:5] (confidence: high para o conflito; medium para o impacto)
- **"Jogável" ainda sem definição operacional**: a interjeição pede main scene, câmera e ilhas geométricas, mas não fixa controles, enquadramento, critério de vitória visível nem se o desafio das ilhas precisa estar implementado no item 1. Sem esses limites, o escopo pode inflar do greybox para o MVP inteiro. [source: STATE:5; GDD:1488-1511] (confidence: high)
- **Nenhuma evidência de runtime**: não há janela, câmera, mesh, build ou captura executada; o workspace tem apenas contratos e sim. A afinidade de Bevy com prototipagem é documental (C5/C7 na avaliação de engines), não medida neste projeto. [source: inspeção de `crates/`; `docs/AVALIACAO-ENGINES-RUST.md:18-30`; STATE:16 (`[NV]` benchmark)] (confidence: high)
- **Churn de API do Bevy 0.x**: a ADR-004 registra explicitamente o custo assumido de "churn de API ~3 em 3 meses do Bevy 0.x" (`:33`); um cliente visual é mais exposto a esse churn do que os crates de contratos/sim. [source: ADR-004:33] (confidence: high para o risco registrado)
- **Especificação 023 vazia**: `specs/023-cliente-greybox/spec.md` é template Draft, sem requisitos, critérios de aceite ou fronteira de crate; nomes, API e divisão de responsabilidades são decisão futura, não evidência atual. [source: inspeção de `specs/023-cliente-greybox/spec.md:1-9`] (confidence: high)
- **Risco de "cliente de fachada"**: uma tela de terminal, um log de eventos ou um headless com saída texto cumpriria a compilação, mas não a main scene/câmera/ilhas pedidas — reproduction do padrão que a ADR-004 já rejeitou em outras formas (`:35-38`). [source: STATE:5; ADR-004:35-38] (confidence: high)
- **Toolchain/MSRV registrados, não compilados**: rust-toolchain 1.99.1 e o MSRV 1.97.1 do crate publicado `bevy@0.20.1` (divergente do 1.100.0 lido no `main`) são registros de 20/11 na ADR-004/converge 021; dependências visuais adicionais podem exigir MSRV maior. [source: ADR-004:13; `specs/021-migracao-bevy/converge.md:7`] (confidence: medium)
